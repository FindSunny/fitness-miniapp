# R2 用户访谈工具包 · 健身小程序（囚徒健身风格）

> **现实条件：只能约到 1–3 人。** 这套工具包已经按 3 个人重写过 —— 人数变了，**方法也得变**。
> 用法：**§0 先看懂判读规则**（不看这个，3 个人的结论一定是错的）→ §1 找谁 → §2 约人话术 → §3 访谈脚本（40 分钟）→ §4 记录模板 → §5 结论提炼表。
> 目标：**3 个不同类型的完整案例**（不是"3 份问卷"）。宁可 3 个人聊透，也不要 8 个人聊成 8 句客套话。

---

## §0 先看懂：n=1–3 时，什么才算证据

**人数少的时候，唯一会犯的致命错误是：把一个人的偏好当成"用户需求"。**
所以规则从"多少人提到"改成"**这条信息会不会改变我的设计决策**"，并且给每条信息标上**证据强度**：

| 强度 | 长什么样 | 怎么用 |
|---|---|---|
| **高** | 你**亲眼看到他这样做**了（卡在哪、先点哪、放弃了什么）；或者他没被问就主动说出来的话 | 可以直接改设计 |
| **中** | 你问他，他想了想，给了个具体例子 | 记下来，改不改都写理由 |
| **低** | 你问他，他说"挺好的""应该有用" —— 客气话 | **只当噪音**，不写进结论 |

> 这条比什么都重要：**3 个人说"这个功能好"，等于 0 条证据**；1 个人在你面前卡了 40 秒找不到"记一组"在哪，就是 1 条硬证据。

**再记住三条边界：**
1. 3 个人**不能**得出"用户都想要 X"——只能说"我见到了 1 种 X"。
2. 3 个人**能**得出的结论是：**某个设计在真实使用中会怎么坏**（因为坏法往往是通用的，而偏好不是）。
3. 聊完必须能回答"我因此要改什么"，如果 3 个人聊完什么决策都没变，要么问法错了，要么产品方向已经对了（两种都要写清楚）。

---

## §1 找谁：3 个名额怎么分配

名额少，所以要**刻意错开类型**，否则 3 个人会给你同一句话。

| 名额 | 类型 | 为什么必须是他 |
|---|---|---|
| 1 号 | **练过又放弃的人**（下过健身 App / 办过卡 / 练过一阵停了） | 最有价值的信息源：他能告诉你"在哪一步不干了"。**这个名额不能省** |
| 2 号 | **正在自己练的人**（在家俯卧撑/深蹲/跑步，没请教练） | 他就是目标用户本体，能验证"十式晋级"对他有没有用 |
| 3 号 | **健身房 / 私教用户**，或**完全不运动的人** | 前者告诉你"我们比私教差在哪"，后者告诉你"为什么根本不进来" |

**怎么挑人（不用广播，直接点名）**：翻一遍微信，按下面顺序想，凑够 3 个就停：
1. 过去一年里，谁在朋友圈/群里发过运动打卡，后来又没声了？（→ 1 号）
2. 谁跟我说过"我最近在家练"？（→ 2 号）
3. 谁有私教、或者谁明确说过"我从来不运动"？（→ 3 号）

> ⚠️ **不要只找健身爱好者**。他们会给你"我想练得更科学""加个数据导出"这种假需求 —— 那不是我们第一个版本要解决的问题。

## §2 约人话术（一对一，直接复制）

### A. 通用版（微信私聊，20 分钟）

> 想请你帮个忙：我在做一个徒手健身的小程序（就是不用器械、在家能练那种），现在能跑起来了，想找 3 个人聊聊 + 上手点一下。
> 40 分钟有点长，其实 **20 分钟就够**，微信语音或者当面都行，随时。
> 主要想搞清楚**大家为什么练不下去**，所以你越说实话越有用 —— 包括"我就是懒"这种也算答案 😄 另外我会做个笔记，方便吗？

### B. 练过又放弃的人（1 号专用）

> 记得你之前好像练过一阵 XX（App / 健身 / 跑步）？我在研究"为什么大部分人坚持不下来"这件事，想听你讲讲当时的情况，20 分钟，不推销任何东西。
> 而且我这次做了个东西，想让你**当面挑毛病** —— 你已经放弃过一次了，正好能看出它哪里会让人放弃 😂

### C. 只给 15 分钟的情况（对方很忙时用）

> 那就 15 分钟：我只问三个问题 —— ①你上一次运动是什么时候，练的什么；②后来为什么没继续；③我做了个小程序，你花 3 分钟点一下，告诉我哪里看不懂。行吗？

## §3 访谈脚本（40 分钟 · 边用边问）

三段式：**先聊过去（15 分钟）→ 再让他上手用（20 分钟）→ 最后复盘（5 分钟）**。
顺序不能反：**先聊过去，才不会被我的产品污染他的回忆。**

### 开聊前 5 分钟检查单

- [ ] 手机上装好**开发版/体验版**（或 `npm run qr` 出预览码），能自己点通一遍，**别现场才发现打不开**
- [ ] 手机满电 / 带了充电宝（访谈全程要录，掉电会中断）
- [ ] 问一句能不能录音（不能就用 §4 模板速记）
- [ ] **别提前给他看设计图、别讲功能清单** —— 讲了就废了，他会顺着你的话说
- [ ] 准备好一句"闭嘴"的自我提醒：**他操作时你不许提示**（见下面铁律）

---

### 第一段 · 过去（15 分钟）—— 只问过去，不问意愿

**0. 开场（1 分钟）—— 先降防御**
> "今天完全不是推销，我也不会给你推荐任何产品。我在做一个自己的小项目，需要搞清楚真实情况。**没有标准答案，说'我就是懒'也是最有用的答案。** 我可能记点笔记，方便吗？"

**1. 现状还原（4 分钟）**

- 你**最近一次**运动是什么时候？做了什么？在哪儿？
- 那一次大概练了多久？中间停了几次？
- 你一般什么时间练？家里哪个位置？（越具体越好 —— 这是在找场景）

> 追问模板："然后呢？""当时你在想什么？""手机放哪儿了？"

**2. 工具使用史（5 分钟）—— 找"真竞品"**

- 你之前用过的那个 App/小程序，**具体怎么用的**？打开后第一件事做什么？
- 大概是哪一天开始不用的？最后一次打开是什么时候？
- 不用的原因是什么？（追问：是烦、是难、还是没效果？）
- 后来你换成什么了？还是干脆不练了？

**3. 放弃时刻（5 分钟）—— 全场最关键**

- 有没有过"练到一半就停了"的经历？**具体是那一次发生了什么？**
- 是身体不行、时间不够、还是心里不想？
- 停下来的那一刻，你脑子里在想什么？
- 后来有没有再想练？是什么让你没再开始？
- 如果那时候有人在旁边说一句话，什么话会有用？（这题能直接产出文案）

---

### 第二段 · 边用边问（20 分钟）—— 3 个人最该看的就是这一段

**怎么做（照做，这几条决定了这次访谈有没有价值）：**

1. 把手机递给他，说：**"这是我自己做的，还很糙。你自己点，随便点，想干嘛就干嘛。我不说话 —— 你遇到看不懂的地方，就当我不在旁边。"**
2. **铁律：他卡住时，你不许指路。** 卡住 = 数据。心里默数秒数，记下来"卡了多久、卡在哪一屏"。
   （唯一例外：卡超过 60 秒、且他开始尴尬了，就说"没事，随便点一个"，然后记下"需要有人指路才能继续"。）
3. 只记**行为**，不问他感受：
   - 他**第一下**点了哪里？（和你预期的入口一样吗）
   - 他在哪一屏**停住 / 往回退 / 反复看**？
   - 他有没有**念出声音**？（"这个是干嘛的""第几式？"—— 这几句话就是文案没写清楚）
   - 他有没有在某个地方**自己发现了好东西**？（那才是产品的真亮点）
4. 给他一个**任务**，别给操作步骤：

   | 任务（就这么说） | 想看什么 |
   |---|---|
   | 「假设你现在想练一下，从打开到记录完一组，你走一遍」 | 主路径能不能自己走通；卡在哪一步 |
   | 「现在你练完了，想知道自己什么时候能升级，你会去哪看？」 | 「还差几次」这个核心反馈，他找得到吗 |
   | 「假设你今天状态不好，只做了几个，你会怎么做？」 | 未达标时他会不会直接退出（然后什么都不留） |

5. 他用完之后，**别问"好不好"**，只问这三句：

   - 「你刚才在这个页面，是想干什么？」（指着他说过"这是干嘛的"的那一屏）
   - 「如果让你改一处，你会改哪里？」
   - 「你会在什么情况下打开它？」（不要问"会不会用"，问"什么时候用"）

**概念确认（如果他全程没看明白你在做什么，收尾时补 1 分钟）**
> "这个东西其实只有六个动作（俯卧撑、深蹲、引体、举腿、桥、倒立撑），每个动作 10 个难度等级，从'推墙'一直到'单臂'，它会告诉你现在在第几级、还差几次升级。不像别的 App 一次给你 50 个动作。"
> 然后只问：「**你听完第一反应是什么？**」

---

### 第三段 · 收尾（5 分钟）

- 你觉得**谁会最需要**这个东西？（帮你找目标人群）
- 有什么我没问到、但你觉得重要的？
- （可选）愿意继续试用第一版的话，我改完发你 —— **愿意继续试用的才算真兴趣**（这比"挺好的"可信一百倍）。

## §4 记录模板（边聊边填，一个人一份）

```
受访者编号：U__    日期：____    类型：放弃型 / 自练型 / 付费型 / 不运动型
画像：性别__ 年龄段__ 职业__ 运动频率__

【原话摘录】← 最重要，至少 3 句，尽量一字不差
1.
2.
3.

【放弃 / 不用的真实原因】（要具体到那一次发生了什么）

【现在用什么替代】（真竞品）

【上手行为观察】← 边用边问那段，只记事实
- 第一下点的是：
- 卡住的地方 / 秒数：
- 念出声的话：
- 自己发现的东西：
- 任务有没有完成（三个任务分别）：

【对"十式晋级"的第一反应】（原话）

【他会主动问的问题】（有 = 真有兴趣）

【他说出的痛点关键词】        【我观察到的（没说出口的）】
```

> 填完自检：**"原话摘录"里有没有一句是我替他说的话？** 有就删掉 —— 那句是噪音。

## §5 结论提炼表（聊完 3 个人，30 分钟内填完）

**怎么读（n=3 专用）：**

- 3 个人都撞上同一个问题 → **几乎可以直接改**（这在真实使用里很少是巧合）
- 2 个人撞上 → 改，但只做最小改动
- 只有 1 个人 → 写进「已知但不做」清单，**并写一句为什么不做**（这本身就是作品集里的加分项：说明你会取舍）
- 3 个人都没碰到的功能 → 记一句"未经真实使用验证"，**不要**因为"我觉得有用"就留着

| # | 现象 / 痛点 | 证据强度（高/中/低） | 几个人 | 原话或行为证据 | 因此要改什么（改/不改/待验证） |
|---|---|---|---|---|---|
| 例 | 记录完一组后不知道下一步干嘛 | 高（看着他停住 20 秒） | 2/3 | "然后呢？" | 改：判定结果旁边加"完成本次训练"按钮 |
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |

**如果以后能加到 5 人以上**：判读规则换回人数版 —— ≥ 半数提到 → 进 MVP；2–3 人 → 需求池；1 人 → 已知但不做。

## §6 三个必须带回答案的问题

1. 用户**上一次放弃**的具体原因是什么？（不是"懒"，要挖到具体触发点）
2. 他现在**用什么替代**？（这才是真正的竞品）
3. "距离升级还差几次"这个反馈，他**有没有真的去看**？（在上手那段观察他是否主动找，而不是问他想不想要）

> 如果这 3 个问题聊完还没有明确答案，说明样本不对或问法要改 —— 先别改代码。

---

## §7 1–3 人最容易犯的 5 个错（开聊前再扫一眼）

1. **边操作边讲解** —— 一讲解，你测的就是自己的嘴，不是产品。
2. **问"你觉得这个功能好吗"** —— 客气话不算证据。只问"你刚才想干什么"。
3. **只聊产品不聊过去** —— 过去是真的，对产品的评价是礼貌的。
4. **把 3 个人的话当 3 亿人的需求** —— 结论里必须写清楚"这是 1 个案例，不是比例"。
5. **聊完不写决策** —— 没落到"改/不改"的访谈等于没做，只剩一段笔记。
