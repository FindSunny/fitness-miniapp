## 0. 结论摘要（只看这段）

1. **有直接竞品，而且口碑很好**：iOS 上有《囚徒健身-徒手锻炼宝典》，4.9 分、1.2 万个评分、免费、含六艺十式进阶标准 + 视频讲解 + 打卡。✅
   👉 但它是 **App 形态、以视频为主**；**小程序端没查到结构化的六艺十式产品** → 差异化在小程序「即开即练、不用下载」+ 极简的晋级判定。
2. **用户真正的痛点不是"缺动作"，而是"坚持不下去"**，而且有研究指出健身 App 会加重羞愧/挫败感，反而削弱动机。✅
   👉 产品要卖的是**进步的确定性**，不是内容量。这恰好是囚徒健身"十式"结构最擅长的事。
3. **平台有 3 个硬约束**：订阅消息（打卡提醒）、服务类目与主体、iOS 虚拟支付。✅/❔
   👉 但作品集项目**可以只做开发版/体验版不公开发布**，约束立刻降级为"基本不用管"。
4. **有 4 个可写进作品集的技术亮点**：结构化数据 + 官方自动化/AI 测试 + VisionKit 人体检测（❔需预研）+ 视觉风格一致性。

### 1.3 竞品拆解维度（后续可建表逐项打分）

内容结构化程度 · **晋级机制** · 器械依赖 · 执行体验（计时/计数/语音）· 打卡与提醒 · 付费点 · 社交 · 视觉风格

**核心观察（🟡）**：主流产品把训练切碎成"30 秒一个动作"的套餐，用户练完没有"我在一条长路上前进"的感觉。囚徒健身的十式结构天生适合做**晋级叙事**——这是最值得做的差异化。

## 2. 用户痛点

### 2.1 有证据的部分 ✅
- 多项研究报道指出：健身 App 对部分用户**产生羞愧、失望、挫败感**，反而削弱运动动机（2025 年，见参考链接）。
- 🟡 推论：这类产品的流失点集中在 ① 首次训练门槛过高 ② 打卡变成负担（游戏化疲劳） ③ **看不到进步**。

### 2.2 对设计的直接指向
- 把"进步"做成**产品结构**（十式进度条 / 距离升级还差几次），而不是靠用户自律。
- 打卡要"轻"：一次训练结束自动记录，别让用户手动填表。
- 首次体验要"立刻有结果"：第一式墙壁俯卧撑谁都能做 10 个 → 立刻拿到晋级进度。

### 2.3 待验证（R2 访谈要问的）
- 你上次练到一半放弃，真实原因是什么？
- 你现在用什么替代（这才是真竞品）？
- 你会为哪一步付钱（如果付费）？

## 3. 平台约束清单

### 3.1 要注意的约束

| 项 | 现状 | 影响 | 出处 |
|---|---|---|---|
| **订阅消息（打卡提醒）** | 分为一次性订阅（用户点一次授权你推一条）与长期订阅（**仅开放给特定行业**，需按类目确认） | 这是打卡类产品的留存命门；不能长期订阅就只能"每次练完引导授权下一条" | 官方文档 ❔ 需按类目核实 |
| **服务类目与主体** | 个人主体可选类目受限；体育/健身相关类目与资质要求需在注册时确认 | 决定"能不能上线"，不影响"能不能开发" | 官方类目页 ❔ 待查 |
| **iOS 虚拟支付** | 小程序在 iOS 端的虚拟支付长期受限（会员/课程类） | 若做付费功能需重新设计 | ❔ 规则时效性强，须看最新公告 |
| **内容版权** | 《囚徒健身》书籍文字与动作插图**有版权**，不可直接搬运 | ⚠️ 关键 | 🟡 常识 |
| **健康内容合规** | 训练建议不宜表述为"治疗/矫正/康复" | 文案措辞注意，加免责声明 | 🟡 |

✅ **好消息**：我们前面做的示意图全部是**自绘矢量图**，不涉及书中插图版权，这条已经天然规避。
✅ **作品集降级方案**：不公开发布（只用开发版/体验版）→ 3/4 类目与支付约束基本不适用。

## 4. 建议的 MVP 边界（作品集版）

**只做一条线，做穿它**：

```
选式 → 跟练（计时/计数）→ 完成 → 打卡记录 → 晋级判定 → 进度可视化
```

- **UI 只做 1 艺**：俯卧撑十式（十式全部可切换，但只做俯卧撑的数据与判定逻辑）
- **数据层全量建好**：六艺 60 式（我们已有名称、标准、自绘姿势图），UI 以后可零成本扩
- **明确不做**：社交/排行榜、直播课、AI 对话教练、支付、视频课程

**技术亮点优先级（性价比从高到低）**：
1. 数据结构化：六艺十式 → JSON + 矢量图，一套数据驱动全部页面
2. **自动测试链路**：miniprogram-automator 主链路 + 云测 AI 生成用例固化回归（差异化最高、成本最低）
3. VisionKit 人体检测（最亮，但必须先花半天做技术预研，能出关键点才值得做）
4. 视觉风格：沿用已验证的卡片体系（浅色卡 + 暗色壁纸两套）
