# e2e/fixtures · 测试夹具（不是产物）

这个目录里的图**故意入库**，用途是给"视觉基线比对"的容忍度做**真实依据的回归测试**。

## home-after-ide-restart.png

和 `../../docs/screenshots/01-home.png` 是**同一个页面状态**（首页全新用户），
但拍在**不同的开发者工具会话**里 —— 后者是建基线那次，前者是重启 IDE 之后那次。

两帧的差异实测（`npm test` 里 Q8 会复算这两个数）：

| 现象 | 数值 |
|---|---|
| 差异位置 | 只有状态栏（时钟 12:17 → 13:44、电量多出 "100"）和**导航栏标题整体下移 1 行** |
| 最大通道差 | 255（一像素的黑白边界） |
| 整文件哈希 | **完全不同** → 纯哈希基线会报"全部 18 张都变了"（狼来了） |
| 行暗度指纹的坏行 | **4 / 737 行 = 0.54%** → 判定"没变" ✓ |

所以基线用的是**行暗度指纹 + 阈值 0.8%**，不是整文件哈希。
这两张图就是这条阈值的"对照组"：**如果哪天阈值调得太严，这个测试会红**。

> 别把这两个文件当产物删掉，也别用它们做别的事 —— 它们唯一的用途就是这个对照。
