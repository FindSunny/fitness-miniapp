E2E · 条数守卫

跑一半崩了，却报全绿

脚本里写着 EXPECTED_CHECKS = 102：实际通过条数对不上就直接报警，不给"中止即成功"的机会。

截图 · 几何守卫

19 张全被标"变了"

工具窗口尺寸变了（363×785 → 377×813）会让指纹逐行失配。现在会单独提示"这不是内容变化"，不再逐张刷屏。

截图 · 空白补拍

一张 10KB 白板算成功

体积下限 + 只对"空白"补拍一次（约 2 秒）；断言失败、页面报错照旧抛出来 —— 补拍不是把红变绿。

在你机器上怎么跑

前置：Node ≥ 20（本机 24）＋ 微信开发者工具（E2E 与截图需要它，且是 Windows 图形环境）。

npm testnpm run e2e:servenpm run e2enpm run e2e:shots

跑 E2E 期间不要改项目文件（会触发重编译、清空页面栈）。E2E 不进 CI：它需要图形环境， 跑不了就不假装绿 —— CI 只跑 npm test。

数据来源：用例名与日志由 tools/collect-test-data.mjs 从仓库与真实运行中采集，随每次提交更新。
