②本地跑测试需要装什么

分三档：跑 Node 断言只需要 Node；跑 E2E 与截图还要微信开发者工具 + 自己的小程序 AppID； 其余（Chrome、上传自检等）都是可选。下面每一条都写了"装在哪个环节必需"和怎么验证。

环境与工具清单
工具 / 环境必需性用途与说明
Node.js 必需 跑 111 条 Node 断言与全部脚本。本机 v24；node:test 自 Node 18 起可用、20 起稳定，建议 ≥20。 无需 npm install（Node 层零依赖）。验证：node -v
Git 必需 拉代码、切分支。仓库带 pre-push 钩子（拦截向 main / prod 的直接 push），需一次性设置： git config core.hooksPath .githooks。验证：git --version
微信开发者工具 仅 E2E E2E 与 19 张截图跑在它里面的真实小程序运行时。要求：已扫码登录 + 设置 → 安全设置 → 开启服务端口；需要图形界面，不能纯命令行 / CI。
小程序 AppID 仅 E2E 编译、真机预览码与 E2E 起项目都要它。用自己的 16 位 AppID： npm run set-appid -- wx你的AppID（仓库若为 touristappid 状态则跑不了上传）。
miniprogram-automator 仅 E2E 微信官方自动化 SDK，本项目唯一的 devDependency（^0.12.1）。 用 npm i 装一次；npm test 完全不需要它。
本地端口 9420 仅 E2E 测试脚本 ↔ 开发者工具之间的自动化服务通道，由 npm run e2e:serve 拉起。 端口被占用时用 E2E_PORT 换一个。
Chrome（可选） 可选 只用于把文档（HTML）渲成 PNG / PDF，与测试无关。

开发者工具的 CLI 默认按 Windows 常见路径查找（C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat， 以及 Program Files 下的同名路径）；装在别处就设 WECHAT_DEVTOOLS_CLI 指向它。

环境变量（脚本真实读取的这几个）
变量默认值作用
WECHAT_DEVTOOLS_CLI两个常见安装路径指定开发者工具 CLI（cli.bat）的位置
E2E_PORT9420自动化服务端口

CF_SKIP_RELEASE_CHECK未设置（即默认自检）上传前跳过 release 自检，仅排查问题时用
第一次搭环境最容易卡住的六个地方
服务端口没开

连不上 9420

开发者工具 → 设置 → 安全设置 → 打开服务端口；不开的话 npm run qr 也会超时。

工具没登录

自动化服务拉不起来

开发者工具需要先扫码登录，脚本再执行 cli auto 才起得来。

会话跑久了

失败点固定在同一个场景

这是工具会话退化（不是 flake）。处置：cli close → npm run e2e:serve → 重跑。

跑测试时改文件

随机失败

工具会重编译、清空页面栈。跑 E2E 期间不要改项目文件。

安装位置特殊

找不到 cli.bat

设 WECHAT_DEVTOOLS_CLI 指向你的 cli.bat 路径即可。

端口被占用

9420 被别的进程占了

用 E2E_PORT 换一个端口（测试脚本与工具同时生效），或先关掉占用进程。

③红了怎么读

测试自己的输出也要能被判读 —— 这三种情况最容易误判。

E2E · 条数守卫

跑一半崩了，却报全绿

脚本里写着 EXPECTED_CHECKS = 102：实际通过条数对不上就直接报警，不给"中止即成功"的机会。

截图 · 几何守卫

19 张全被标"变了"

工具窗口尺寸变了（363×785 → 377×813）会让指纹逐行失配。现在会单独提示"这不是内容变化"，不再逐张刷屏。

截图 · 空白补拍

一张 10KB 白板算成功

体积下限 + 只对"空白"补拍一次（约 2 秒）；断言失败、页面报错照旧抛出来 —— 补拍不是把红变绿。

在你机器上怎么跑

前置 Node ≥ 20（本机 24）＋ 微信开发者工具 —— E2E 与截图需要它，且需 Windows 图形环境。
命令 npm testnpm run e2e:servenpm run e2enpm run e2e:shots
注意 跑 E2E 期间不要修改项目文件（会触发重编译、清空页面栈）。E2E 不进 CI：它需要图形环境，跑不了就不假装绿，CI 只跑 npm test。
数据来源 用例名与日志由 tools/collect-test-data.mjs 从仓库与真实运行中采集（日志已脱敏），随每次提交更新。
